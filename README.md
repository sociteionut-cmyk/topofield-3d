# TopoField 3D

Aplicație PWA de topografie pentru teren (React + Vite + TypeScript). Datele (proiecte, fotografii, puncte) rămân doar în browserul utilizatorului (IndexedDB); acest repository conține exclusiv codul.

- Adresa online: https://sociteionut-cmyk.github.io/topofield-3d/
- Dezvoltare: `npm install`, `npm run dev`
- Verificări: `npm run typecheck`, `npm test`
- Build pentru publicare: `TOPOFIELD_BASE=/topofield-3d/ npm run build`, apoi conținutul din `dist/` se publică în branch-ul `gh-pages`.

Nu adăugați în acest repository fotografii, coordonate sau copii de siguranță reale.
